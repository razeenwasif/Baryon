# MIP practice quiz

Open `mip-practice-quiz.html` in Safari or another browser. It is a standalone,
offline HTML file with all three reference images embedded; it has no external
scripts, fonts, network calls or answer key. Navigate with Previous, Next or the
question selector. Your typed answers and chosen options are saved in browser
storage when available. Clear my answers removes only this quiz’s stored answers.

To use Fairy, enable Quiz hints and keep written answers to clipboard enabled.
Start at Question 1, let Fairy observe each setup, and scroll down to see the
choices on Questions 1 and 4. Move through the questions in order so the dependent
questions have their source context. A star indicates a written answer was copied;
paste it into a separate scratch area to compare with your own answer. The quiz
itself does not read or write your clipboard.

Question 6 explicitly uses your confirmed meaning: remove `− under(xj)` from the
big-M coefficient. The original Yes/No questions use radio buttons, and the
written questions preserve their supplied word limits.

`answer-key.md` is separate so Fairy cannot see it through the quiz screen.
`verification.md` records the live Astra screenshot test and its limitations.
`validate-maths.py` runs independent finite mathematical checks with Python 3.
